# 最终修改清单

## 产品与流程

- 将无终点聊天改为一次即可完成的有限流程：3 项预判、6 项初选、2 项反转、2 项取舍、2 项换位，共 15 项。
- 每轮由 Dify 生成新的六个生活故事、标题、配套选项和反转文案；生成失败会明确标记固定题库回退。
- 最终说明书包含三维倾向、初选证据、两条反转对照和预判／取舍／换位对照。

## 可信边界

- 题号、行为锚点、分值、顺序、原始选择和证据 ID 由 Node 后端掌管。
- 增加严格的题集、报告、证据、反转和拓展字段校验；模型不能增加题目、修改分数或伪造证据。
- 增加请求幂等、revision 检查、同源检查、存档原子写入和旧存档兼容。

## Dify

- 本机 Dify 1.19.0 已真实完成 `scenes` 与 `report` 两次核心任务。
- 最终 DSL 从成功发布的 Workflow 通过官方 `AppDslService`、`include_secret=false` 重新导出。
- DSL 已更新为 0.7.0，包含 OpenAI provider plugin 1.1.0 依赖和 3 个节点。
- 移除了会覆盖最终 DSL 的旧开发期生成器及 npm 命令。

## PowerContext

- 接入真实 PowerContext 1.5.0 HTTP Server，为每轮创建独立 Scope。
- 15 项选择逐项写入 content source 和 Atomic Memory，并保存真实写入回执。
- 报告前召回并核对全部标识与选择原文，再把召回体放入 Dify `report` 的 `payload.recalled`。
- 增加写入失败保留答案、待同步状态、显式重试和召回不完整时阻断报告。
- 增加项目内固定版本安装、前台运行、用户服务启动／停止／状态脚本。

## 验证与交付

- 自动测试 18/18；覆盖 4096 种初选组合和 36864 种初选／反转组合。
- 完成退出重进同一轮、Node 重启恢复、无 Cookie 会话隔离、PowerContext 重启召回和真实 PC 故障重试。
- 增加无密钥配置示例、一页说明、真实验收摘要、验证样例、脱敏 Dify／PowerContext 证据和提交检查表。
- 排除 `.env`、运行存档、数据库、日志、依赖目录、缓存、旧开发历史和内部代理指令。
